# Statistical Analysis of NASA Confirmed Exoplanets

Data Analytics mini project: EDA, star-type grouping, habitable zones, hypothesis tests, regression and clustering on 6,150 exoplanets.

**Project page:** https://YOUR-USERNAME.github.io/exoplanet-analysis/

## Contents
- `index.html` project page (GitHub Pages)
- `Exoplanet_Analysis_Final.py` / `.ipynb` full analysis
- `figures/` charts produced by the script
- `report.pdf` the report (add your file here)

```
pip install -r requirements.txt
python Exoplanet_Analysis_Final.py
```
